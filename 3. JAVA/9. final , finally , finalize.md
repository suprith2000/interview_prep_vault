
The terms `final`, `finally`, and `finalize` in Java are distinct and serve different purposes, even though they sound similar. Here’s a breakdown of each:

### 1. `final` (Keyword)

- **Purpose**: Used to define constants, prevent inheritance, or restrict overriding.
    
- **Usage**: It can be applied to variables, methods, and classes.
    
    - **final variable**: When a variable is declared as `final`, its value cannot be changed after initialization.
        `final int MAX_VALUE = 100;`
        
    - **final method**: When a method is declared as `final`, it cannot be overridden by subclasses.
```
public final void display() {
    System.out.println("This method cannot be overridden");
}

```
        
    - **final class**: When a class is declared as `final`, it cannot be extended.
```
public final class MathUtility {
    // class contents
}

```
        

### 2. `finally` (Block)

- **Purpose**: Ensures that a block of code is executed, no matter whether an exception is thrown or not, typically used with `try-catch` blocks.
    
- **Usage**: The `finally` block is always executed after the `try-catch`, even if an exception occurs or if there is a `return` statement inside the `try` block.
    
```
try {
    // risky code
} catch (Exception e) {
    // handle exception
} finally {
    // cleanup code, always executed
    System.out.println("This block is always executed");
}

```
    

### 3. `finalize()` (Method)

- **Purpose**: Called by the garbage collector before an object is destroyed to allow cleanup operations like releasing resources (e.g., closing file handles or database connections).
    
- **Usage**: It is a method in the `Object` class that you can override. However, its use is discouraged in modern Java since garbage collection is unpredictable, and it doesn’t guarantee when or if `finalize()` will be called.
    
```
protected void finalize() throws Throwable {
    try {
        // cleanup code
    } finally {
        super.finalize();
    }
}

```
    
    **Note**: Starting with Java 9, `finalize()` has been deprecated due to its unpredictable behavior and performance issues.
    

### Summary:

- **`final`**: A keyword used to create constants, prevent method overriding, and prevent class inheritance.
- **`finally`**: A block used in exception handling to ensure the execution of code, regardless of exceptions.
- **`finalize()`**: A method used for cleanup before garbage collection, but it is deprecated and should be avoided.
