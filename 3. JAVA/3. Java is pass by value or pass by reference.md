
Java is **pass-by-value**, but this can be a bit confusing due to how it works with **objects**.

### **Pass-by-value Explanation:**

In Java, when you pass a variable to a method, you are passing a **copy** of the value of that variable.

1. **For primitive types** (e.g., `int`, `double`, `char`, etc.), this means that a copy of the actual value is passed. Any modifications to the parameter within the method do not affect the original value outside the method.
    
    Example:
```
public class Test {
    public static void modify(int a) {
        a = 10;  // this change is local to the method
    }

    public static void main(String[] args) {
        int x = 5;
        modify(x);
        System.out.println(x);  // x remains 5, not 10
    }
}

```
    
2. **For objects**, the situation is slightly different. When an object is passed to a method, the value of the reference (the memory address) is passed **by value**. The method gets a copy of the reference, but it still points to the same object in memory. Therefore, changes to the object’s internal state inside the method **will be reflected** outside the method. However, if you try to change the reference itself, the original reference in the calling method is unaffected.
    
    Example:
```
public class Test {
    public static void modifyObject(Person p) {
        p.name = "John";  // changes the name property of the original object
    }

    public static void main(String[] args) {
        Person person = new Person("Alice");
        modifyObject(person);
        System.out.println(person.name);  // Output: John
    }
}

```
    
    However, if you try to reassign the object reference inside the method, the original reference will not change:
```
public class Test {
    public static void reassignObject(Person p) {
        p = new Person("Bob");  // this change affects only the local reference
    }

    public static void main(String[] args) {
        Person person = new Person("Alice");
        reassignObject(person);
        System.out.println(person.name);  // Output: Alice (unchanged)
    }
}

```
    

### **Summary:**

- For **primitives**, Java passes a copy of the value.
- For **objects**, Java passes a copy of the reference, but the method can modify the object’s data. However, the reference itself cannot be changed outside the method.
