### 1. **What is EC2 in AWS?**

- **Answer**: EC2 (Elastic Compute Cloud) is a web service that provides resizable compute capacity in the cloud. It enables users to launch and manage virtual servers (instances) and offers a variety of instance types optimized for different use cases, such as general-purpose, compute-optimized, memory-optimized, and storage-optimized instances. EC2 instances are highly configurable, allowing users to specify CPU, memory, storage, and network settings, as well as to choose between on-demand, reserved, and spot instances.

### 2. **What are the different types of EC2 instances?**

- **Answer**: EC2 instances are categorized into several types based on different use cases:
    - **General Purpose**: (e.g., T4g, T3, T3a, M6g, M5) for balanced CPU and memory needs.
    - **Compute Optimized**: (e.g., C6g, C5, C5a) ideal for compute-bound applications.
    - **Memory Optimized**: (e.g., R6g, R5, X1) for memory-intensive workloads.
    - **Storage Optimized**: (e.g., I3, D2, H1) optimized for storage-intensive applications.
    - **Accelerated Computing**: (e.g., P4, G4, Inf1) for GPU and FPGA workloads.

### 3. **What are the differences between On-Demand, Reserved, and Spot instances?**

- **Answer**:
    - **On-Demand Instances**: Pay for compute capacity by the hour or second. Ideal for short-term or unpredictable workloads.
    - **Reserved Instances (RI)**: Provide a discount on usage charges in exchange for committing to a 1 or 3-year term. Good for steady-state workloads.
    - **Spot Instances**: Allow you to bid on unused EC2 capacity at lower prices. Suitable for fault-tolerant or flexible workloads that can tolerate interruptions.

### 4. **What is an EBS volume, and how is it used with EC2?**

- **Answer**: Amazon Elastic Block Store (EBS) is a persistent storage option for EC2 instances. EBS volumes are network-attached storage devices that remain available independently of the lifecycle of an instance. They are highly durable, offering various types optimized for throughput and IOPS performance. EBS volumes can be attached to or detached from instances, and snapshots of EBS volumes can be created for data backup and restoration.

### 5. **How does EC2 Auto Scaling work?**

- **Answer**: **EC2 Auto Scaling** automatically adjusts the number of EC2 instances in response to changing application demand, helping maintain application availability. You can set scaling policies that define the minimum and maximum number of instances in an auto-scaling group. Auto Scaling adds or removes instances based on CloudWatch metrics, such as CPU usage or network traffic, to ensure consistent application performance.

### 6. **What are Security Groups in EC2?**

- **Answer**: Security Groups act as virtual firewalls for your EC2 instances, controlling inbound and outbound traffic. They allow users to specify rules that permit or deny traffic based on IP addresses, ports, and protocols. Security groups are stateful, meaning any allowed inbound traffic automatically has corresponding outbound rules. Changes to security group rules are applied immediately, providing dynamic control over access.

### 7. **What is the difference between Security Groups and Network ACLs?**

- **Answer**:
    - **Security Groups** are instance-level, stateful firewalls. They apply only to specific EC2 instances and automatically allow return traffic.
    - **Network ACLs (Access Control Lists)** are subnet-level, stateless firewalls that operate at the VPC level. They provide an additional layer of security and require explicit rules for both inbound and outbound traffic.

### 8. **Explain the EC2 pricing model.**

- **Answer**: EC2 offers various pricing models to cater to different use cases:
    - **On-Demand**: Pay-as-you-go with no upfront cost.
    - **Reserved Instances (RIs)**: Lower costs in exchange for a long-term commitment (1 or 3 years).
    - **Spot Instances**: Variable pricing for unused capacity at a significant discount, best for flexible workloads.
    - **Savings Plans**: Commit to a certain amount of compute usage for one or three years across EC2, Fargate, and Lambda for discounted pricing.
    - **Dedicated Hosts**: Physical servers dedicated to a single customer for regulatory or compliance needs.

### 9. **How does Amazon EC2 achieve high availability and fault tolerance?**

- **Answer**: EC2 enables high availability through **Availability Zones (AZs)** within a region, which are isolated locations with independent power, cooling, and networking. By deploying instances across multiple AZs, applications can survive failures in one AZ. Additionally, services like **Elastic Load Balancing (ELB)** and **Auto Scaling** help maintain fault tolerance by distributing traffic across instances and scaling instances based on demand.

### 10. **How do you create an AMI in EC2?**

- **Answer**: An **Amazon Machine Image (AMI)** is a preconfigured template for launching EC2 instances. To create an AMI:
    1. Set up and configure an EC2 instance.
    2. Select the instance, and choose “Create Image” from the Actions menu in the EC2 console.
    3. Specify details like image name, volume configuration, and instance settings.
    4. The AMI is saved and can be used to launch new instances with the same configuration.

### 11. **What is EC2 Instance Metadata and User Data?**

- **Answer**: **Instance Metadata** is data about an EC2 instance, such as instance ID, IP addresses, and security groups, accessible from within the instance at `http://169.254.169.254/latest/meta-data/`. **User Data** is a script or cloud-init directives that run during the first boot of an instance, typically used to automate configurations (e.g., installing software or setting environment variables).

### 13. **What is the purpose of Elastic IP in EC2?**

- **Answer**: **Elastic IP (EIP)** is a static, public IP address that can be associated with an instance, providing a consistent IP address for applications and end-users. If an instance with an Elastic IP is stopped or terminated, the Elastic IP can be re-associated with a different instance, ensuring high availability for applications that require a fixed IP.

### 14. **How do you monitor EC2 instances?**

- **Answer**: **Amazon CloudWatch** is used to monitor EC2 instances. It provides metrics such as CPU utilization, disk read/write, and network traffic. Custom metrics and alarms can be configured to notify users of abnormal behavior, and **CloudWatch Logs** capture log files from instances for further analysis.

### 15. **What are Placement Groups in EC2?**

- **Answer**: Placement Groups control the physical placement of instances within an AWS region:
    - **Cluster Placement Group**: Places instances close together within a single AZ for low-latency networking.
    - **Spread Placement Group**: Spreads instances across different hardware to reduce failure risk.
    - **Partition Placement Group**: Divides instances into logical partitions, with each partition on separate racks, useful for large distributed applications.
