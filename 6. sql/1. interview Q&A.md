### 1. **What is the difference between `WHERE` and `HAVING` clauses?**

- **Answer**: The `WHERE` clause is used to filter rows before any grouping takes place, while the `HAVING` clause is used to filter groups after the `GROUP BY` clause has created groups of rows. `WHERE` cannot be used with aggregate functions, but `HAVING` can.

### 2. **Explain the different types of joins in SQL.**

- **Answer**:
    - **INNER JOIN**: Returns records that have matching values in both tables.
    - **LEFT (OUTER) JOIN**: Returns all records from the left table and matched records from the right table. If there is no match, NULL is returned for columns from the right table.
    - **RIGHT (OUTER) JOIN**: Returns all records from the right table and matched records from the left table. If there is no match, NULL is returned for columns from the left table.
    - **FULL (OUTER) JOIN**: Returns all records when there is a match in either left or right table. Rows without a match in one of the tables will show NULL for the unmatched table.

### 3. **What is a `PRIMARY KEY` and a `FOREIGN KEY`?**

- **Answer**:
    - A `PRIMARY KEY` uniquely identifies each row in a table and cannot have NULL values.
    - A `FOREIGN KEY` is a column or set of columns in one table that references the `PRIMARY KEY` of another table, creating a link between the two tables.

---

### 4. **What is a `SELF JOIN`?**

- **Answer**: A `SELF JOIN` is a join where a table is joined with itself. It can be useful when comparing rows within the same table, such as finding employees with the same manager.

---

### 5. **How do you fetch only unique values from a column in SQL?**

- **Answer**: Use the `DISTINCT` keyword to retrieve unique values. For example:
    
    sql
    `SELECT DISTINCT column_name FROM table_name;`
    

---

### 6. **What is the difference between `DELETE`, `TRUNCATE`, and `DROP`?**

- **Answer**:
    - `DELETE`: Removes specified rows from a table. Can use `WHERE` to filter rows, and it is a DML command.
    - `TRUNCATE`: Removes all rows from a table but keeps the table structure for future use. It cannot be rolled back in most databases and is a DDL command.
    - `DROP`: Deletes the entire table, including its structure. The table cannot be used again unless recreated. It is also a DDL command.

---

### 7. **How do you find the second highest salary in a table?**

- **Answer**:
    - Using `LIMIT` and `ORDER BY`:
        
        sql
        `SELECT salary FROM employees ORDER BY salary DESC LIMIT 1 OFFSET 1;`
        
    - Or, using a subquery:
        
        sql
        `SELECT MAX(salary) FROM employees WHERE salary < (SELECT MAX(salary) FROM employees);`

### 8. **Explain `GROUP BY` and how it's used.**

- **Answer**: The `GROUP BY` clause is used to arrange identical data into groups. It's often used with aggregate functions like `SUM`, `AVG`, `COUNT`, etc., to apply calculations to each group. For example:
    
    sql
    `SELECT department, COUNT(*) FROM employees GROUP BY department;`
    

---

### 9. **What is `ACID` in SQL databases?**

- **Answer**: `ACID` stands for Atomicity, Consistency, Isolation, and Durability. It is a set of properties to ensure reliable processing of database transactions:
    - **Atomicity**: Each transaction is treated as a single unit that either succeeds completely or fails completely.
    - **Consistency**: The database remains in a valid state before and after the transaction.
    - **Isolation**: Concurrent transactions are isolated from each other.
    - **Durability**: Once a transaction is committed, it remains in the database even if there’s a system failure.

---

### 10. **What is a `VIEW` in SQL, and why is it used?**

- **Answer**: A `VIEW` is a virtual table created by a query. It can simplify complex queries, provide an additional security layer by restricting access to certain columns, and can be used to present data in a specific format. For example:
    
    sql
    `CREATE VIEW employee_view AS SELECT id, name, department FROM employees;`
    

---

### 11. **How can you improve the performance of a SQL query?**

- **Answer**:
    - Use indexes on columns that are frequently used in `WHERE`, `JOIN`, and `ORDER BY` clauses.
    - Avoid using `SELECT *`; instead, specify only the columns you need.
    - Use `LIMIT` to restrict the result set when appropriate.
    - Avoid `LIKE` patterns starting with `%` as they are slower.
    - Use appropriate data types and normalize tables to reduce redundancy.

---

### 12. **What is the difference between `UNION` and `UNION ALL`?**

- **Answer**: `UNION` combines the result sets of two queries and removes duplicate records. `UNION ALL` combines the result sets but includes all duplicates. `UNION ALL` is faster because it doesn't check for duplicates.
