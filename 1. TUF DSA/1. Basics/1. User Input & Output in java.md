In Java, input and output (I/O) operations are essential for interacting with the user, reading and writing data to files, and handling data streams. Java provides various classes and methods to perform I/O operations.

### 1. **User Input using `Scanner` Class**

The `Scanner` class in Java is commonly used to obtain input from the user via the console. It's part of the `java.util` package.

```
import java.util.Scanner;

public class UserInputExample {
    public static void main(String[] args) {
        // Create a Scanner object to read input from the console
        Scanner scanner = new Scanner(System.in);

        // Prompt the user for their name
        System.out.print("Enter your name: ");
        String name = scanner.nextLine();

        // Prompt the user for their age
        System.out.print("Enter your age: ");
        int age = scanner.nextInt();

        // Output the received input
        System.out.println("Hello, " + name + "! You are " + age + " years old.");

        // Close the scanner to avoid resource leaks
        scanner.close();
    }
}

```

### Example: Get float, double and String Input
```
import java.util.Scanner;

class Input {
    public static void main(String[] args) {
    	
        Scanner input = new Scanner(System.in);
    	
        // Getting float input
        System.out.print("Enter float: ");
        float myFloat = input.nextFloat();
        System.out.println("Float entered = " + myFloat);
    	
        // Getting double input
        System.out.print("Enter double: ");
        double myDouble = input.nextDouble();
        System.out.println("Double entered = " + myDouble);
    	
        // Getting String input
        System.out.print("Enter text: ");
        String myString = input.next();
        System.out.println("Text entered = " + myString);
    }
}
```


- `Scanner.nextLine()` reads an entire line of input.
- `Scanner.nextInt()` reads an integer input.
- `System.out.println()` is used to display output.

### 2. **User Output using `System.out`**

Java's standard output stream (`System.out`) is used to print information to the console.

#### Common Output Methods:

- `System.out.print()` – Prints text without a new line.
- `System.out.println()` – Prints text followed by a new line.
- `System.out.printf()` – Formats output similarly to `printf` in C.
```
public class OutputExample {
    public static void main(String[] args) {
        String name = "Alice";
        int age = 30;

        // Print using println (with automatic newline)
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);

        // Print using printf (formatted output)
        System.out.printf("Name: %s, Age: %d%n", name, age);  // %s for String, %d for int
    }
}

```

### 3. **File I/O with `FileReader`, `BufferedReader`, `FileWriter`, `BufferedWriter`**

Java also supports reading and writing files using the `java.io` package. Below are some examples using file streams.

#### Example: Reading from a File
```
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class FileInputExample {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(new FileReader("input.txt"))) {
            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

```

Example: Writing to a File
```
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class FileOutputExample {
    public static void main(String[] args) {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter("output.txt"))) {
            bw.write("Hello, World!");
            bw.newLine();
            bw.write("This is a file output example.");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

```

### 4. **Using `Streams` for I/O**

Java 8 introduced the `Streams API`, which can also be used for I/O operations when dealing with collections.

#### Example: Using Streams for File Reading
```
import java.nio.file.Files;
import java.nio.file.Paths;
import java.io.IOException;
import java.util.stream.Stream;

public class StreamFileInputExample {
    public static void main(String[] args) {
        try (Stream<String> lines = Files.lines(Paths.get("input.txt"))) {
            lines.forEach(System.out::println);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

```
