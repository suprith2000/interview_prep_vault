In Java, function arguments are **passed by value**. However, it's important to understand how this applies to both **primitive data types** and **object references**, as the behavior can sometimes appear similar to "pass by reference" in certain cases.

### 1. **Pass by Value for Primitives:**

- When passing a **primitive type** (e.g., `int`, `double`, `boolean`) to a method, the method receives a **copy** of the actual value.
- Any changes made to the parameter inside the method **do not affect** the original value.

Example:
```
public class Example {
    public static void modifyPrimitive(int num) {
        num = 10; // modifies the copy, not the original
    }

    public static void main(String[] args) {
        int a = 5;
        modifyPrimitive(a);
        System.out.println(a); // Output: 5
    }
}

```
In this case, `a` remains unchanged because the method operates on a copy of `a`.

### 2. **Pass by Value for Object References:**

- When passing an **object** to a method, Java still uses pass by value. However, this time the value passed is a **copy of the reference** to the object.
- This means that the method can modify the **object's internal state** (because both the original and the copied references point to the same object), but it **cannot change the reference itself**.

Example:
```
public class Example {
    static class MyObject {
        int value;
    }

    public static void modifyObject(MyObject obj) {
        obj.value = 10; // modifies the object through the reference
    }

    public static void main(String[] args) {
        MyObject obj = new MyObject();
        obj.value = 5;

        modifyObject(obj);
        System.out.println(obj.value); // Output: 10
    }
}

```
Here, the object's `value` is changed to `10` because the method operates on the same object that `obj` refers to.
### 3. **Attempt to Change the Reference:**

If you try to reassign the object inside the method, the reassignment will affect only the local copy of the reference, not the original reference.

Example:
```
public class Example {
    static class MyObject {
        int value;
    }

    public static void reassignReference(MyObject obj) {
        obj = new MyObject(); // reassigns the local copy of the reference
        obj.value = 20; // affects only the new object, not the original one
    }

    public static void main(String[] args) {
        MyObject obj = new MyObject();
        obj.value = 5;

        reassignReference(obj);
        System.out.println(obj.value); // Output: 5
    }
}

```
Here, the reference to the original `obj` in `main` is unchanged after calling `reassignReference`, so `obj.value` remains `5`.

### Summary:

- Java is **pass by value**.
- For **primitive types**, the actual value is passed, and changes inside the method don't affect the original variable.
- For **objects**, a copy of the reference is passed, allowing methods to modify the object’s state but not change the reference itself.
