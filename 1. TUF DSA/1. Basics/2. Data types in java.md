In Java, data types specify the size and type of values that can be stored in variables. They are divided into two broad categories:

### 1. **Primitive Data Types**

These are the most basic data types built into the language. Java has 8 primitive types:

| Data Type | Size                   | Description                                                          |
| --------- | ---------------------- | -------------------------------------------------------------------- |
| `byte`    | 1 byte (8 bits)        | Stores whole numbers from -128 to 127.                               |
| `short`   | 2 bytes (16 bits)      | Stores whole numbers from -32,768 to 32,767.                         |
| `int`     | 4 bytes (32 bits)      | Stores whole numbers from -2^31 to 2^31 - 1.                         |
| `long`    | 8 bytes (64 bits)      | Stores whole numbers from -2^63 to 2^63 - 1.                         |
| `float`   | 4 bytes (32 bits)      | Stores fractional numbers (single precision, 6-7 decimal digits).    |
| `double`  | 8 bytes (64 bits)      | Stores fractional numbers (double precision, 15 decimal digits).     |
| `char`    | 2 bytes (16 bits)      | Stores a single 16-bit Unicode character (e.g., 'A', 'a', '1', '@'). |
| `boolean` | 1 bit (depends on JVM) | Stores `true` or `false` values.                                     |
### 2. **Non-Primitive (Reference) Data Types**

These include objects and arrays, and they do not store values directly but refer to locations in memory.

- **String**: Stores sequences of characters. Strings in Java are objects, which means they come with built-in methods for string manipulation.
    `String str = "Hello, World!";`
    
- **Arrays**: A collection of elements of the same type, accessed by index.
    int[] arr = {1, 2, 3, 4, 5}; 
- **Classes**: A blueprint for creating objects (a type of reference type).
- **Interfaces**: Define methods that a class must implement.
- **Enums**: A special data type that defines a set of named constants.
- Unlike primitive types, reference types can be null.
### Differences Between Primitive and Non-Primitive Types:

- **Primitive types** are predefined by Java, whereas **non-primitive types** are user-defined or built into the Java library.
- **Primitive types** always hold values, while **non-primitive types** hold references to objects.
- **Primitive types** are stored in stack memory, while **objects** (non-primitive) are stored in heap memory.

### Wrapper Classes

Each primitive type has a corresponding wrapper class that allows primitive data to be treated as objects.

| Primitive Type | Wrapper Class |
| -------------- | ------------- |
| `byte`         | `Byte`        |
| `short`        | `Short`       |
| `int`          | `Integer`     |
| `long`         | `Long`        |
| `float`        | `Float`       |
| `double`       | `Double`      |
| `char`         | `Character`   |
| `boolean`      | `Boolean`     |
### Type Casting

Java allows both implicit and explicit type casting between compatible types.

1.  **Implicit (Widening)**: Happens automatically when converting a smaller type to a larger type.
```
int i = 100;
long l = i;  // Implicit conversion

```
2. **Explicit (Narrowing)**: Requires explicit casting when converting from a larger to a smaller type.
```
`double d = 9.8; int i = (int) d;  // Explicit conversion`
```
