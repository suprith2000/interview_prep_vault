## 1.Given two integers N1 and N2, find their greatest common divisor.

The Greatest Common Divisor of any two integers is the largest number that divides both integers.

**Example 1:****Input:**N1 = 9, N2 = 12
        Output:3  
         Factors of 9: 1, 3 and 9
         Factors of 12: 1, 2, 3, 4, 6, 12
         Common Factors: 1, 3 out of which 3 is the greatest hence it is the GCD.
		 

Solution  1:  (brute force)

```                            
public class Main {
    public static int findGcd(int n1, int n2) {
        int gcd = 1;
        for (int i = 1; i <= Math.min(n1, n2); i++) {
            if (n1 % i == 0 && n2 % i == 0) {
                gcd = i;
            }
        }
        return gcd;
    }

    public static void main(String[] args) {
        int n1 = 20, n2 = 15;
        int gcd = findGcd(n1, n2);
        System.out.println("GCD of " + n1 + " and " + n2 + " is: " + gcd);
    }
}                       
```

### Solution 2 : (Euclidean Algorithm)
The Euclidean Algorithm is a method for finding the greatest common divisor of two numbers. It operates on the principle that the GCD of two numbers remains the same even if the smaller number is subtracted from the larger number.

To find the GCD of n1 and n2 where n1 > n2:

1. Repeatedly subtract the smaller number from the larger number until one of them becomes 0.
2. Once one of them becomes 0, the other number is the GCD of the original numbers.

Eg, n1 = 20, n2 = 15:
gcd(20, 15) = gcd(20-15, 15) = gcd(5, 15)
gcd(5, 15) = gcd(15-5, 5) = gcd(10, 5)
gcd(10, 5) = gcd(10-5, 5) = gcd(5, 5)
gcd(5, 5) = gcd(5-5, 5) = gcd(0, 5)
Hence, return 5 as the gcd.

Code  :
```                        
public class Main {
    public static int findGcd(int a, int b) {
        while(a > 0 && b > 0) {
            if(a > b) {
                a = a % b;
            }
            else {
                b = b % a;
            }
        }
        if(a == 0) {
            return b;
        }
        return a;
    }

    public static void main(String[] args) {
        int n1 = 20, n2 = 15;
        int gcd = findGcd(n1, n2);
        System.out.println("GCD of " + n1 + " and " + n2 + " is: " + gcd);
    }
}                         
```

## 2.Given two integers a and b, write a function `lcmAndGcd()` to compute their LCM and GCD. The function takes two integers a and b as input and returns a list containing their LCM and GCD.

```
class Solution {
    static Long[] lcmAndGcd(Long A , Long B) {
        Long[] ans = new Long[2];
        
        // Calculate GCD using the Euclidean algorithm
        Long gcd = gcd(A, B);
        
        // Calculate LCM
        Long lcm = (A * B) / gcd;
        
        // Store the LCM and GCD in the array
        ans[0] = lcm;
        ans[1] = gcd;
        
        return ans;
    }

    // Method to calculate GCD using the Euclidean algorithm
    static Long gcd(Long A, Long B) {
        if (B == 0) {
            return A;
        }
        return gcd(B, A % B);
    }
};
```
