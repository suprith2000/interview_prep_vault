
You are given an integer **_‘n’_**.

Function **_‘sumOfDivisors(n)’_** is defined as the sum of all divisors of ‘n’.

Find the sum of ‘sumOfDivisors(i)’ for all ‘i’ from 1 to ‘n’.

**Example:**

```
Input: ‘n’  = 5

Output: 21

Explanation:
We need to find the sum of ‘sumOfDivisors(i)’ for all ‘i’ from 1 to 5. 
‘sumOfDivisors(1)’ = 1
‘sumOfDivisors(2)’ = 2 + 1 = 3
‘sumOfDivisors(3)’ = 3 + 1 = 4
‘sumOfDivisors(4)’ = 4 + 2 +1 = 7 
‘sumOfDivisors(5)’ = 5 + 1 = 6
Therefore our answer is sumOfDivisors(1) + sumOfDivisors(2) + sumOfDivisors(3) + sumOfDivisors(4) + sumOfDivisors(5) = 1 + 3 + 4 + 7 + 6 = 21.
```

brute force Approach :

```
public class Solution {
    public static int divisors(int n){
        int sum=0;
        for(int i=1; i<=n; i++){
            if (n%i==0) {
                sum+=i;
            }
        }
        return sum;
    }
    public static int sumOfAllDivisors(int n){
       int result = 0;
       int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum+=divisors(i); 
        }
        return sum;
    }
}
```

optimized approach :

### Explanation:

- For each `i`, it is a divisor of all numbers that are multiples of `i`.
- The number of multiples of `i` between 1 and `n` is `n / i`.
- Thus, for each `i`, you add `i` to the sum `n / i` times, since `i` is a divisor for all multiples of `i`.

### Example Walkthrough:

For `n = 5`, the above approach computes:

- For `i = 1`, multiples are 1, 2, 3, 4, 5 → Sum: `1 + 1 + 1 + 1 + 1 = 5`
- For `i = 2`, multiples are 2, 4 → Sum: `2 + 2 = 4`
- For `i = 3`, multiple is 3 → Sum: `3`
- For `i = 4`, multiple is 4 → Sum: `4`
- For `i = 5`, multiple is 5 → Sum: `5`

The total sum is `5 + 4 + 3 + 4 + 5 = 21`.

### Time Complexity:

The time complexity of this approach is O(n)O(n)O(n), which is much more efficient than the brute-force solution. This should be sufficient to handle large values of `n` within time limits.

Code:
```
public class Solution {
    public static int sumOfAllDivisors(int n) {
        int result = 0;
        // Loop through all numbers from 1 to n
        for (int i = 1; i <= n; i++) {
            // Add i as a divisor to all its multiples
            result += (n / i) * i;
        }
        return result;
    }
    public static void main(String[] args) {
        int n = 5;
        System.out.println(sumOfAllDivisors(n));  // Output: 21
    }
}
```
